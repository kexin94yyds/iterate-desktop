# Support

## Desktop source and builds

Use GitHub Issues for reproducible iterate Desktop and MCP server bugs. Search
existing issues first and include the public commit or release, operating
system, expected behavior, actual behavior, and a minimal synthetic
reproduction.

Do not attach valid QR codes, tokens, raw private conversations, unredacted
logs, or private project archives.

## Security

Use the private process in [SECURITY.md](SECURITY.md), not a public issue.

## Official closed-source products

The official iOS app, browser extension, VS Code extension, hosted relay, and
control-plane services are not supported through this desktop source
repository. Use the support channel shipped with the relevant official
product.

## Community expectations

Maintainers may close requests that cannot be reproduced, depend on excluded
private products, or fall outside the desktop repository's scope.
